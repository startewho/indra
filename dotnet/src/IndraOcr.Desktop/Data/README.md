# Bundled models

This folder ships with the desktop app and is the default model path
(`<app>/Data`).

- Source: https://huggingface.co/datalab-to/indra-ocr/tree/v1.1.0
- Revision: `v1.1.0`
- Files: det/rec/rec_cjk/rec_rtl/rec_world/order/orient/script ONNX models,
  n-gram language models, metadata, and the optional math models.
- License: OpenRAIL-M; see `LICENSE` in this folder.

The models are read-only data for Indra OCR. They are not part of the source
code license.
